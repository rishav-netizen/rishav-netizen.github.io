# PORTFOLIO DESIGN & ENGINEERING CONSTITUTION

## 1. Aesthetic Direction: "CADENCE // HELIX"
We are building an Awwwards-caliber creative developer portfolio hosted on GitHub Pages (`github.io`).
- **Inspirations:** `junkbranding.com` (HUD telemetry, particle/spring physics, sound/motion toggles, editorial typography) and `aahana-surya.github.io` (diegetic systems-check preloader, packet downlink tables, interactive canvas constellations/spheres).
- **Core Motif:** `Motif: Helical Curl × Polyrhythm × 176 SPM Cadence` (fusing Percussion/Drumming, Distance Running, and Curly Hair Helical Physics).

## 2. STRICT ANTI-AI-SLOP BANS
- NEVER use default purple/indigo/blue neon gradients (`from-purple-500 to-blue-500`).
- NEVER use standard centered SaaS hero sections with two pill buttons.
- NEVER use generic rounded-2xl glassmorphism Bento grids with Lucide icons inside colored circles.
- NEVER use Inter, Roboto, or Arial.
- NEVER write generic AI copy ("Passionate full-stack developer crafting seamless digital experiences").

## 3. Visual & Technical Mandates
- **Palette:** High-contrast Obsidian Asphalt (`#0A0A0C`), Warm Bone Parchment (`#F2EFE9`), Cinder Track Clay / Terracotta (`#E04F33`), and Brass Cymbal Gold (`#D4AF37`).
- **Typography:** Load Google Fonts: `'Syne'` or `'Instrument Serif'` for massive brutalist/editorial display headers, and `'JetBrains Mono'` for all HUD telemetry, timestamps, BPM readouts, and tags.
- **Layout:** Exposed 1px structural hairlines (`rgba(242, 239, 233, 0.12)`), asymmetric Swiss editorial grids, fixed corner HUD readouts, and smooth inertia scrolling.
- **Audio & Motion:** Web Audio API procedural drum synthesis (zero external MP3 dependencies required—synthesize kick, rimshot, hi-hat, and sub-bass directly in JS) + persistent `SOUND [ON/OFF]` and `MOTION [ON/OFF]` HUD toggles.

# STRICT VISUAL & ARCHITECTURE RULES (NO AI SLOP)
1. BANNED COLORS: NEVER use orange (#E04F33), terracotta, red, warm beige, cream, or yellow.
2. BANNED LAYOUTS: NEVER use visible background CSS grid lines (`linear-gradient` grid backgrounds are strictly forbidden). NEVER use boxed containers with colored borders. NEVER use giant cheesy magazine slogans ("A Body of Work in Motion", "Interfaces with a pulse").
3. BANNED FONTS: NEVER use Instrument Serif or italic serif accent words. Use ONLY ultra-clean geometric sans (`Space Grotesk` or `Plus Jakarta Sans` with wide letter-spacing) and crisp technical monospace (`JetBrains Mono`) at small, whisper-quiet sizes (10px–13px) for HUD telemetry.
4. CORE ARCHITECTURE: Like `junkbranding.com`, 100% of the viewport (`position: fixed; inset: 0`) is a live Three.js WebGL GPGPU/Shader Particle Simulation in deep abyssal black (`#020307`) with bioluminescent ice-cyan (`#7DD3FC`), ethereal violet (`#C084FC`), and pure starlight white (`#F8FAFC`).
